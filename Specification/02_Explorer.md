\# Google Drive Manager PRO



\# 02 - EXPLORER



Version : 1.0.0



Statut : En conception



\---



\# Objectif



Explorer permet de parcourir intégralement un Google Drive.



Il doit fonctionner même sur un Drive contenant plusieurs millions de fichiers.



Il ne modifie jamais les données.



Il analyse uniquement.



\---



\# Fonctionnalités



\## Navigation



\- Arborescence complète

\- Navigation par dossiers

\- Navigation récursive

\- Ouverture rapide

\- Retour arrière



\---



\## Informations affichées



Pour chaque dossier :



\- Nom

\- ID Google Drive

\- Chemin complet

\- Nombre de sous-dossiers

\- Nombre de fichiers

\- Taille totale

\- Taille directe

\- Date de création

\- Dernière modification

\- Propriétaire

\- Partagé (Oui / Non)



Pour chaque fichier :



\- Nom

\- Extension

\- Type MIME

\- Taille

\- Date création

\- Date modification

\- Propriétaire

\- URL

\- ID

\- Chemin complet
